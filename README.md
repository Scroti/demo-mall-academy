# demo-mall-academy

Showcase pentru client — proiectul **MallAcademy**.

Live: https://scroti.github.io/demo-mall-academy/

## Conținut

- `index.html` — landing page cu link-uri către toate materialele
- `design-preview.html` — preview interactiv (10 screen-uri) al interfeței
- `plan-de-executare.pdf` — planul de execuție al proiectului
- `architecture.pdf` — arhitectura tehnică a soluției

## Hosting

Servit prin GitHub Pages din branch-ul `main`, root `/`.

Pentru a activa: **Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`**.
